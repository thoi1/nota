# UI/input contract

Five tool keys in order: Select (1), Pencil (2), Eraser (3), Waveform Draw (4) with adjacent shape dropdown, Nota Warp (5). Identical native buttons/icons/menu in both contexts. Each editor has exactly one tool; only shape/settings are global. Fresh 4 activates last shape; another fresh 4 in that context cycles Sine/Triangle/Sawtooth/Square/Freehand and wraps. Tooltips/accessibility include names and shortcut labels. Typing, modifiers, keypad and foreign/modal windows are excluded. Warp visuals describe an unavailable tempo-editing engine, never a simulated map.
