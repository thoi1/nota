# UI contract

The inline toolbar contains Select Tool, Pencil Tool, Eraser Tool, Waveform Draw Tool and Nota Warp Tool. Toggle selection cannot leave the group empty. Tool names are accessible names and exact English tooltip strings. The secondary waveform menu offers Sine/Triangle/Sawtooth/Square/Freehand and practical amplitude/cycle/phase presets. Automation visibility remains independently controlled. Eraser cursor is drawn through the native Glyph system. Nota Warp selection visibly explains unavailable ruler tempo-grid editing; no stretching command is issued.
